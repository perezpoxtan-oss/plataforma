# Documentación

Cada módulo se entrega con cuatro piezas; un cambio que altera una pantalla o regla no se integra sin actualizar su documento.

| Carpeta | Contenido |
|---|---|
| `tecnico/` | Arquitectura, tablas, endpoints, permisos y reglas de negocio de cada módulo |
| `usuario/` | Guías paso a paso por tarea, con capturas del entorno de QA |
| `cursos/` | Lecciones por rol: Operador de caseta, Supervisor, Administrador del cliente, Integrador técnico |
| `decisiones/` | Registros de decisiones de arquitectura (ADR), numerados |

Documentos rectores (fuera del repositorio): Documento Maestro, Mapa de módulos, Inventario funcional e Inventario de base de datos del sistema actual.
